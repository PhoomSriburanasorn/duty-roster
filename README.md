# ระบบจัดตารางเวร (duty-roster)

เครื่องมือจัดตารางเวรรายเดือน — ไฟล์ HTML เดียว ไม่ต้องติดตั้งอะไร ไม่ต้องมี server

## วิธีใช้
เปิด `index.html` ด้วยเบราว์เซอร์ หรือเสิร์ฟผ่าน launch.json:

```bash
python3 -m http.server 8092 --directory duty-roster
```

กดปุ่ม **📥 โหลดโจทย์จริง — กันยายน 2569** ในแท็บ ① เพื่อดูตัวอย่างที่ตั้งค่าครบ

## ลำดับการใช้งาน (แท็บเรียงตามลำดับงาน)
| # | แท็บ | ทำอะไร |
|---|---|---|
| ① | พนักงาน | รายชื่อ + ตำแหน่ง (วางรายชื่อทีเดียวได้) |
| ② | เดือน & ห้อง | วันทำการ · ห้อง · **บทบาทของแต่ละช่องเวร** · ห้ามอยู่ห้องเดิมติดกันกี่วัน |
| ③ | โควตา & เป้าหมาย | ตารางเป้าหมายรายคน × รายห้อง + **การกระทบยอด** |
| ④ | เงื่อนไข | วันไม่ว่าง · คู่ห้าม · กฎ soft |
| ⑤ | ตารางเวร | จัด · ตรวจ · แก้มือ · ส่งออก |

## แนวคิดหลัก

**ช่องเวรมี "บทบาท" ได้** — แทนที่จะบอกแค่ "ห้องนี้ 3 คน" ให้กำหนดรายช่องว่า
ช่อง 1 = Senior, ช่อง 2–3 = Junior ตรงกับกฎแบบ "INFI ต้องมี Senior 1 + Junior 2"

**โควตาแบบล็อกเป๊ะ ไม่ใช่แค่เพดาน** — ตารางในแท็บ ③ ใส่ได้ทั้ง
"รวมทั้งเดือนกี่เวร" และ "ห้องไหนกี่เวร" ต่อคน · เว้นว่าง = ปล่อยให้ระบบตัดสิน

**การกระทบยอดก่อนจัด (pre-flight)** — ระบบบวกเลขให้ก่อนว่าโจทย์เป็นไปได้ไหม
เช่น ผลรวมเป้ารายคน ≠ ช่องเวรทั้งเดือน, โควตาห้องเกินที่ต้องการ, คนว่างไม่พอในบางวัน,
ตำแหน่งที่ช่องบังคับมีกำลังไม่พอ, คู่ที่ห้ามอยู่วันเดียวกันมีเป้ารวมเกินจำนวนวัน
→ **ถ้าโจทย์ขัดกันเอง จะบอกว่าขัดข้อไหน แทนที่จะจัดออกมาผิด ๆ**

**เงื่อนไข 2 ระดับ**
- *Hard* (ผลลัพธ์จะไม่ผิด): วันไม่ว่าง · 1 คน 1 ห้อง/วัน · บทบาทช่อง · คู่ห้าม
  (ทั้งวัน / ห้องเดียวกัน / **เฉพาะห้องที่ระบุ**) · เป้าเวรรวม · โควตารายห้อง ·
  สูงสุดต่อสัปดาห์ · ห้ามอยู่ห้องเดิมติดกันเกิน N วัน
- *Soft* (เปิด/ปิด + ปรับน้ำหนัก): ไม่ขึ้นเวรติดกัน · กระจายรายสัปดาห์ · หมุนเวียนห้อง ·
  หมุนเวียนคู่ · เกลี่ยคนที่ไม่ได้ล็อกเป้า · ให้ห้องกลุ่มหนึ่งมากกว่าอีกกลุ่ม

**รายงานตรวจสอบสร้างเอง** — ทุกเงื่อนไขที่ตั้งไว้กลายเป็นข้อตรวจ ✅/❌ พร้อมรายการที่ผิด
ไม่มีการเขียนตายตัว เพิ่มกฎใหม่ = มีข้อตรวจใหม่อัตโนมัติ

**ตัวเลขอ้างอิงที่ยุติธรรม** — ข้อ "ขึ้นเวรติดกัน" เทียบกับ *ขั้นต่ำที่เป็นไปได้ทางคณิตศาสตร์*
(คนที่ต้องได้ 15 เวรใน 22 วัน ยังไงก็ต้องติดกันอย่างน้อย 4 ครั้ง) ไม่ใช่เทียบกับศูนย์

## การจัดและการแก้
- **🎲 สุ่มใหม่** — สร้างหลายรอบ ซ่อมโควตาให้ตรงเป๊ะ แล้วเกลี่ย soft ต่อ (~2 วินาที)
- **🔧 เกลี่ยเพิ่ม** — เกลี่ยต่อจากตารางเดิมโดยไม่รื้อทั้งใบ กดซ้ำได้เรื่อย ๆ
- **🔒 ล็อกช่อง** — ล็อกช่องที่พอใจ แล้วสุ่มใหม่เฉพาะที่เหลือ
- **คลิกช่อง / ลากสลับ** — แก้มือได้ ระบบบอกเหตุผลว่าใครลงไม่ได้เพราะอะไร แต่ไม่บล็อก

## ผลทดสอบกับโจทย์จริง (กันยายน 2569)
13 คน · 3 ห้อง (SIM 2 / TOMO 2 / INFI 3) · 22 วันทำการ · 154 ช่องเวร
→ **ผ่านเงื่อนไขบังคับครบ 16 ข้อ** ใช้เวลา ~2 วินาที
โควตารายคนและรายห้องตรงเป๊ะทุกคน · SIM 44 / TOMO 44 / INFI 66 / รวม 154

## ข้อควรรู้
- ข้อมูลอยู่ใน `localStorage` ของเบราว์เซอร์เครื่องนั้น — ใช้ **⤓ สำรอง / ⤒ กู้คืน** (.json) เพื่อย้ายเครื่อง
- **วันหยุดนักขัตฤกษ์ต้องคลิกปิดเอง** ในแท็บ ② — ไม่ได้ฝังปฏิทินไว้ เพราะมติ ครม. แต่ละปีไม่เหมือนกัน
- ลบพนักงาน = ลบเงื่อนไข/เวรของคนนั้นทุกเดือน ถ้าแค่พักงานให้ติ๊ก "ใช้งาน" ออกแทน
- CSV มี BOM → เปิดใน Excel ภาษาไทยไม่เพี้ยน และแนบผลตรวจสอบเงื่อนไขมาท้ายไฟล์ด้วย
