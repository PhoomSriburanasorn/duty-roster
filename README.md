# ระบบจัดตารางเวร (duty-roster)

เครื่องมือจัดตารางเวรรายเดือน — ไฟล์ HTML เดียว ไม่ต้องติดตั้งอะไร ไม่ต้องมี server

## วิธีใช้
เปิด `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย) หรือเสิร์ฟผ่าน launch.json:

```bash
python3 -m http.server 8092 --directory duty-roster
```

## ข้อมูลเก็บที่ไหน
`localStorage` ของเบราว์เซอร์ที่เปิด → **ผูกกับเครื่อง + เบราว์เซอร์ตัวนั้น** ไม่ sync ข้ามเครื่อง
ใช้ปุ่ม **⤓ สำรองข้อมูล / ⤒ กู้คืน** (ไฟล์ .json) เพื่อย้ายเครื่องหรือแบ่งให้คนอื่นใช้

## โครงสร้างข้อมูล 2 ชั้น
| ชั้น | เก็บอะไร |
|---|---|
| ถาวร | พนักงาน, ตำแหน่ง (+ กฎ "สูงสุดกี่คนต่อห้อง"), กฎคู่ห้ามยืนพื้น, ห้องเริ่มต้น |
| รายเดือน | วันทำการ, ห้อง+จำนวนคนต่อห้อง, วันลา, โควตาเวร, กฎคู่เฉพาะเดือน, น้ำหนัก soft rules, ล็อกช่อง, ตารางที่จัดแล้ว |

เดือนใหม่กด ▶ ที่หัวจอ → ระบบสร้างเดือนใหม่ให้อัตโนมัติ (จ–ศ เป็นวันทำการ)
กด **📄 คัดลอกการตั้งค่าจากเดือนก่อน** เพื่อยกห้อง/กฎมาใช้ต่อ (ไม่ลากวันลาและตารางเก่ามาด้วย)

## เงื่อนไข 2 ระดับ
**Hard — ผลลัพธ์จะไม่ผิดข้อพวกนี้**
- วันลา / วันไม่อยู่
- 1 คนได้เวรได้ห้องเดียวต่อวัน
- กฎตำแหน่ง เช่น Senior ไม่เกิน 1 คนต่อห้อง
- คู่ที่ห้ามอยู่ด้วยกัน (เลือกได้ว่า "ห้องเดียวกัน" หรือ "วันเดียวกัน")
- โควตาเวรสูงสุดรายคน
- "ห้ามอยู่เวรติดกัน" ถ้าติ๊ก *ห้ามเด็ดขาด*

**Soft — เปิด/ปิด + ปรับน้ำหนักได้เอง**
เกลี่ยจำนวนเวร · ไม่อยู่เวรติดกัน · เว้นระยะ ≥N วัน · หมุนเวียนห้อง · หมุนเวียนคู่

## วิธีจัด
สุ่มสร้าง 220 แบบ → ให้คะแนนแต่ละแบบ (จำนวนช่องที่ลงคนไม่ได้ + ความเหลื่อมของจำนวนเวร + soft penalties)
→ เก็บอันดีสุด → เกลี่ยต่อด้วยการสลับคู่แบบสุ่ม 900 รอบ เก็บเฉพาะที่คะแนนดีขึ้น

- **🎲 สุ่มใหม่** = ได้ตารางหน้าตาต่างไปแต่ถูกกติกาเหมือนกัน
- **🔒 ล็อกช่อง** = กดล็อกช่องที่พอใจ แล้วสุ่มใหม่เฉพาะช่องที่เหลือ
- **คลิกช่อง** = เลือกคนเอง (โชว์เหตุผลว่าทำไมบางคนลงไม่ได้ แต่ไม่บังคับห้าม)
- **ลากสลับ** ระหว่างช่องได้ ระบบตรวจให้ทันที ช่องที่ผิดกฎขึ้นแดง / ไม่เหมาะขึ้นเหลือง

ถ้าจัดไม่ครบ ระบบบอกตรง ๆ ว่าวันไหน ห้องไหน และวันนั้นมีคนว่างกี่คนเทียบกับที่ต้องการ

## ข้อควรรู้
- **วันหยุดนักขัตฤกษ์ต้องคลิกปิดเอง** ในแท็บ "ตั้งค่าเดือนนี้" — ไม่ได้ฝังปฏิทินวันหยุดไว้
  เพราะมติ ครม. แต่ละปีไม่เหมือนกัน ฝังไว้แล้วผิดจะอันตรายกว่าไม่มี
- ลบพนักงาน = ลบเงื่อนไข/เวรของคนนั้นทุกเดือน ถ้าแค่พักงานให้ติ๊ก "ใช้งาน" ออกแทน
- Export เป็น CSV (มี BOM เปิดใน Excel ภาษาไทยไม่เพี้ยน) หรือกด 🖨️ พิมพ์
